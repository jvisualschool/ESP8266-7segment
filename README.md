# 🚀 ESP8266 Animation Live Studio: MAX7219 + OLED

초소형 디스플레이에 생명을 불어넣는 디지털 미디어 아트 프로젝트입니다. 
당초 단순하게 숫자를 띄우는 용도로 쓰이던 7세그먼트 MAX7219 모듈을 픽셀 매트릭스로 재해석하여, **총 50가지의 역동적이고 몽환적인 픽셀 애니메이션**을 만들어냅니다. 메인 스테이지에서 빛이 춤추는 동안, 옆에 위치한 OLED 화면은 마치 실시간 중계 방송의 대시보드(Live Broadcast)처럼 현재 진행 중인 애니메이션의 상황을 관객에게 친절하게 도슨트(Docent)해 줍니다. 

아날로그적 스코어보드와 사이버펑크 스타일의 현황판이 완벽한 조화를 이루는 이 특별한 작품을 만나보세요.

## 📱 디바이스 및 기능적 특징 (Device Characteristics)

* **🧠 ESP8266 (NodeMCU / Wemos D1 Mini):** 프로젝트의 두뇌 역할을 하며, I2C(OLED)와 SPI(MAX7219) 두 가지 서로 다른 통신 방식을 지연 없이 동시에 완벽하게 소화합니다. 
* **📺 0.96" I2C OLED (도슨트 대시보드):** 메인 조명인 붉은색 LED에 시선을 방해하지 않으면서도, 애니메이션의 고유 번호, 제목, 상세 설명을 픽셀 아트 폰트로 섬세하게 전달하여 시청자의 이해를 돕습니다. (해상도 128x64 픽셀 기반의 정보 시스템)
* **🔥 MAX7219 8-Digit Display (메인 퍼포먼스):** 7개의 막대기와 1개의 소수점(Dot)으로 이루어진 정식 명칭 **"7-세그먼트 디스플레이(7-Segment Display)"** 모듈입니다. 본 프로젝트에서는 8개의 숫자가 연달아 붙어 있는 "8-Digit" 모델을 이용해, 이 '숫자 전용 디스플레이'라는 태생적 한계를 깨고, 오로지 점과 선의 조합(ON/OFF)만으로 무한한 시각적 리듬감과 연속성을 창출해 냅니다.
* **⏱️ 완벽한 타이밍 & 유기적 시퀀스:** 
  - **심호흡(AWAKENING):** 부팅 시 기기 전체 픽셀이 켜지고, **6초간 서서히 호흡하며 밝아졌다가 어두워집니다.** 이는 기계가 스스로 깨어나 워밍업을 하는 느낌을 선사합니다.
  - **카운트다운(COUNTDOWN):** 관객의 기대감을 증폭시키는 블록 방식의 타이머 시퀀스가 지나간 후 메인 루프에 진입합니다.
  - 각각의 단일 애니메이션은 `millis()` 베이스 비-동기식 타이머를 통해 **정밀하게 6초씩 보장**되어 아주 우아하고 여유로운 감상이 가능합니다.
* **🌐 웹 시뮬레이터 내장 (`preview.html`):** 로컬 환경의 폴더 내에 HTML 파일이 제공됩니다. 브라우저만 창을 열면 하드웨어 없이도 기기와 100% 동일한 로직, 동일한 타이밍으로 그려지는 50종 아트워크를 **실시간 웹 기반 라이브**로 경험하실 수 있습니다.

## 💻 개발자의 관점 (Developer's Perspective)

이 프로젝트는 극한으로 제한된 마이크로컨트롤러 메모리와 연산 자원 내에서 **상태 구조화(State Management)와 비동기 렌더링 파이프라인(Non-blocking Rendering)**을 구축하여 완성도를 끌어올린 엔지니어링의 결정체입니다.

1. **추상화된 디스플레이 버퍼 구조 (State Buffer Architecture)**
   하드웨어(MAX7219 모듈)에 즉각 명령을 내리지 않습니다. 대신 `byte state[8]`이라는 일종의 추상화된 8바이트 가상 버퍼 배열에 그려질 그림의 논리를 먼저 연산합니다. 연산이 완료된 후 `drawState()` 함수를 통해 한 프레임을 하드웨어로 일괄 방출(Flush)함으로써 화면이 찢어지는 현상(Tear-free)을 원천 차단했습니다.
2. **함수 포인터와 구조체를 이용한 극강의 확장성 (Open-Closed Principle)**
   총 50개의 애니메이션 로직을 처리해야 합니다. 이를 지저분한 `switch-case`문이나 수천 줄의 `loop()` 구문에 쏟아 붓는 대신, `AnimRule` 이라는 커스텀 스코어(Score) 구조체에 OLED에 띄울 문자열과 실행할 `void (*func)()` 함수 포인터를 연결했습니다.
   그 결과 `playlist[50]` 이라는 거대한 선형 데이터 배열이 탄생했고, 무한 루프 구간(`loop()`)은 단 4줄의 코드로 50개의 거대 세계를 깔끔하게 순회합니다. 버그에 강하며 애니메이션 단위 테스트와 교체가 몹시 자유롭습니다.
3. **비트마스킹(Bitmasking) 마법 연산**
   하나의 점등 튜브에는 7개의 세그먼트 막대기와 1개의 소수점(DP)이 있습니다(총 8비트). 이를 제어하기 위해 0과 1의 세계인 이진 연산을 극한으로 활용했습니다. 
   비트를 덧입히는 `| (OR)`, 지우는 `~ (NOT)` `& (AND)`, 상태를 토글하는 `^ (XOR)`, 밀어내는 `<< (SHIFT)` 등을 조립하여, 코드가 짧아지고 속도는 극대화된 경량화 퍼포먼스를 달성했습니다.

## 🎨 미디어 아티스트의 관점 (Media Artist's Perspective)

본 작품의 기획 의도는 **"디지털 매체의 가장 기초적인 최소 단위만으로, 과연 우리의 감정을 흔들 수 있을까?"** 에 대한 실험이자 대답입니다.

1. **도슨트(Docent)와 메인 캔버스(Canvas)의 분리**
   OLED는 일관적이고 무미건조한 정보 제공자(해설자)로 사용하고, 강렬하고 뜨거운 붉은빛을 발산하는 MAX7219는 감정 표현의 극단적 창구(피사체)로 설정했습니다. 이 이원화된 인터페이스는 관객으로 하여금 마치 미술관 관람 동선 한가운데 서 있는 듯한 입체감을 부여합니다.
2. **리듬과 생명 메타포 (Rhythm & Metaphor)**
   서로 독립되고 차가운 LED 칩들이 유기체적인 리듬을 가지면 놀랍게도 그것은 생명처럼 느껴집니다. 초반 6초의 'Awakening Breathing', 심전도를 그리는 '13. EKG LINE', 음파를 타는 '15. VOLUME EQ', 펄스 파동인 '23. PULSE' 등의 작품은 관객에게 심장 박동과 시각적 맥박을 기계에 동기화시키는 마술 같은 경험을 선사합니다.
3. **레트로 포맷의 반항, 그리고 미니멀리즘 (Minimalism)**
   7세그먼트 튜브는 '계산기 숫자'를 표시하라고 만들어진 매우 통제된 스펙의 한계를 가집니다. 프로젝트는 이 금기를 부수고 빗방울, 기차 라인, 우주 은하수, 레이저, 디지털 글리치(Glitch)라는 압도적인 스케일의 추상적 형상을 단 몇 개의 점과 획으로 함축하는 **레트로 미니멀리즘 예술**로 빚어냈습니다.

## 🛠️ 따라 해보기 (How to Reproduce)

누구나 이 감동적인 프로젝트를 1시간 내 복제하고 즐길 수 있습니다. 완벽하게 준비되었습니다.

### 1단계: 준비물 (Hardware)
- **ESP8266 보드** (Wemos D1 Mini 혹은 NodeMCU 권장)
- **MAX7219 8-Digit Display Module** (본 프로젝트의 주인공)
- **0.96" I2C OLED Display** (128x64 해상도 SSD1306 계열)
- 점퍼 와이어 및 브레드보드

### 2단계: 하드웨어 배선 (Wiring Setup)

> 보드의 전원에 따라 안정성이 달라지므로 **디스플레이끼리 전원 핀을 이격시켜 주는 것**이 팁입니다.
> 
**A. 디더링 중계용 OLED (I2C 연결)**
* `VCC` ➡ ESP8266 `3.3V` (OLED용)
* `GND` ➡ ESP8266 `GND`
* `SDA` ➡ ESP8266 `D2` (NodeMCU GPIO 4)
* `SCL` ➡ ESP8266 `D1` (NodeMCU GPIO 5)

**B. 메인 퍼포먼스 모듈 MAX7219 (SPI 연결)**
* `VCC` ➡ ESP8266 `5V` (or Vin/VU. 붉은색 LED 발광의 강렬함을 위해 5V 권장)
* `GND` ➡ ESP8266 `GND`
* `DIN` ➡ ESP8266 `D7` (NodeMCU GPIO 13)
* `CS`  ➡ ESP8266 `D8` (NodeMCU GPIO 15)
* `CLK` ➡ ESP8266 `D5` (NodeMCU GPIO 14)

### 3단계: 라이브러리 설치 (Arduino IDE 환경)
아두이노 IDE의 "라이브러리 매니저(Library Manager)"에서 다음 3가지 필수 라이브러리를 설치합니다.
1. `LedControl` (작성자: Eberhard Fahle - MAX7219 메인 컨트롤러)
2. `Adafruit SSD1306` (OLED 하드웨어 그래픽 제어)
3. `Adafruit GFX Library` (OLED 및 좌표 도형 그래픽 처리 엔진)

### 4단계: 컴파일과 작품 업로드 (Upload)
1. 리포지토리에서 클론하거나 다운로드한 `ESP32-MAX7219.ino` 메인 코드를 엽니다.
2. 상단 메뉴 **툴(Tools) > 보드(Board)** 에서 자신이 연결한 ESP8266 종류를 선택합니다.
3. 데이터 케이블 연결 포트를 설정하고 **업로드 화살표**를 클릭합니다.
4. 모든 조용한 방의 불을 끄고, 6초 단위로 진행되는 50가지의 자신만의 사이버 네온 갤러리를 감상하십시오!
